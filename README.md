# LifeRSS

A local-first, keyboard-driven Firefox RSS/Atom reader.

## M1

- Firefox sidebar for subscriptions, unread and all articles
- RSS/Atom feed fetching with local persistence
- Inoreader-style keyboard shortcuts
- Read/unread state retained across restarts

## Coming later

- Silent feed discovery and toolbar subscription action
- Firefox bookmarks as Read Later (Firefox Sync handles bookmark syncing)
- OPML import/export
- Dropbox sync for feeds, read state, and settings only

No recommendations, sharing, tags, full offline reader, or custom bookmark syncing.
